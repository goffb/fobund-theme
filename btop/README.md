# fobund-btop

fobund theme for [btop](https://github.com/aristocratos/btop).

## install

clone the repository and copy the theme file to your btop themes directory:

```bash
git clone https://github.com/goffb/fobund-theme.git
mkdir -p ~/.config/btop/themes
cp fobund-theme/btop/fobund.theme ~/.config/btop/themes/fobund.theme
```

open btop, press esc, select options, then set color_theme to fobund.
