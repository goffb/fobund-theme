# fobund-kitty

fobund theme for [kitty](https://github.com/kovidgoyal/kitty).

## install

clone the repository and copy the theme file to your kitty configuration directory:

```bash
git clone https://github.com/goffb/fobund-theme.git
mkdir -p ~/.config/kitty
cp fobund-theme/kitty/fobund.conf ~/.config/kitty/fobund.conf
```

add this line to ~/.config/kitty/kitty.conf:

```conf
include fobund.conf
```

kitty will reload its configuration automatically.
