# fobund-xfce4-terminal

fobund theme for [xfce4-terminal](https://docs.xfce.org/apps/xfce4-terminal/start).

## install

clone the repository and copy the theme preset to your xfce4-terminal color schemes directory:

```bash
git clone https://github.com/goffb/fobund-theme.git
mkdir -p ~/.local/share/xfce4/terminal/colorschemes
cp fobund-theme/xfce4-terminal/fobund.theme ~/.local/share/xfce4/terminal/colorschemes/fobund.theme
```

open xfce4-terminal preferences and select fobund from edit → preferences → colors → presets.
